# DharRakshak API

Backend for the DharRakshak crop assistant (Team Dynaminds, HackShift): leaf
analysis with the Daksh159/plant-disease-mobilenetv2 model, weather, risk,
action cards, mock loan data, and a Groq-powered multilingual chatbot.

API docs: `/docs` · Health: `/api/health` · Source: https://github.com/Shubham271005/Dynaminds-IIITD

Loan data is sample data only — no bank integration.
